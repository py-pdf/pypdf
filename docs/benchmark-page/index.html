Each value is a benchmark's median time divided by the time of a fixed calibration workload that ran on the same machine. Lower is faster. Because the slow and fast GitHub runners cancel out, values from different machines are comparable, including yours: run make benchmark.

These values are iterations per second, so higher is faster. Each run used whichever GitHub runner was free, and the runners differ in speed by up to a factor of two, so most jumps come from the machine, not from pypdf. Some benchmarks also included disk access and assertions. Do not compare these numbers with the calibrated results.
